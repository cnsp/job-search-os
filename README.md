# Job Search Operating System

Source for the GitHub Pages site at `https://[your-username].github.io/job-search-os/`.

Published via Jekyll with the Minima theme. MathJax enabled for equation rendering.

## Local preview

```bash
gem install bundler jekyll
bundle init
bundle add jekyll minima jekyll-feed jekyll-seo-tag
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
